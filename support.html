Quick Answers

Common installation & playback help.

Android asks “Install unknown apps”

That prompt appears whenever an APK is installed from Chrome/browser instead of Google Play. Tap Settings → Allow from this source, install LYRA, and you can toggle browser permission right back off afterward.

Local songs not showing up?

Make sure audio permission (READ_MEDIA_AUDIO) is allowed under Android App Info → Permissions, then pull to refresh inside Library to re-index your folders.
